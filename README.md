# Aratrika's 20th Birthday Surprise

A small birthday website made by Rupam for Aratrika. It opens with a birthday greeting, shares six photo memories with personal wishes, includes a birthday note, and ends with three video messages.

## Files

- index.html contains the birthday page.
- styles.css contains the layout, colors, responsive styles, and decorations.
- script.js opens the greeting and adds a short confetti effect.
- images/1.jpeg through images/6.jpeg are the photo memories.
- images/main_video.mp4, images/Your_Friends.mp4, and images/my_friend.mp4 are the video messages.

## Open the page

Open index.html in a modern browser. The page uses local photos and videos. The decorative fonts are loaded from Google Fonts when an internet connection is available; system fallbacks are included.

To change a greeting, caption, or wish, edit its text in index.html. To replace a photo or video, keep the same asset path or update the matching source in that file.
